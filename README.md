# ফসল বন্ধু — কৃষি সহায়ক AI (প্রোটোটাইপ ডেমো)

একটা মোবাইল-রেডি PWA (Progressive Web App) যেখানে কৃষক ফসলের রোগের নাম বা ওষুধের নাম লিখে/বলে মিলে যাওয়া সব কীটনাশক/ছত্রাকনাশক/আগাছানাশক খুঁজে পাবেন — বাংলা, ইংরেজি, ফোনেটিক (Banglish), এমনকি বানান ভুল হলেও। ডেটা এখন সরাসরি আপনার **গুগল শীট থেকে লাইভ** আসে।

## 📲 Android-এ অ্যাপ হিসেবে ইনস্টল করবেন যেভাবে

Android-এ সত্যিকারের "Install" বাটন পেতে হলে অ্যাপটা **HTTPS দিয়ে হোস্ট করা** থাকতে হবে (`file://` দিয়ে সরাসরি খুললে ইনস্টল অপশন আসবে না)। সবচেয়ে সহজ ফ্রি উপায় — **Netlify Drop** (লগইন লাগে না):

1. কম্পিউটারে ব্রাউজারে যান: **https://app.netlify.com/drop**
2. `foshol-bondhu` ফোল্ডারটা (zip না, extract করা পুরো ফোল্ডার) সরাসরি সেই পেজে **ড্র্যাগ করে ছেড়ে দিন**
3. কয়েক সেকেন্ডে একটা লাইভ লিংক পাবেন (যেমন `https://random-name-123.netlify.app`)
4. সেই লিংক ফোনে Chrome দিয়ে খুলুন
5. উপরে হেডারে **"অ্যাপ ইনস্টল করুন"** বাটন দেখা যাবে (অথবা Chrome মেনু ⋮ → **"Add to Home screen" / "Install app"**) — ট্যাপ করুন
6. এখন ফোনের হোম স্ক্রিনে "ফসল বন্ধু" আইকন দেখা যাবে, আসল অ্যাপের মতো ফুল-স্ক্রিনে খুলবে, অফলাইনেও চলবে

*(Netlify Drop-এর লিংক অস্থায়ী/ডেমো লেভেলের জন্য যথেষ্ট। স্থায়ী হোস্টিং লাগলে ফ্রি Netlify/Vercel/GitHub Pages একাউন্ট খুলে একই ফোল্ডার ডিপ্লয় করলেই স্থায়ী লিংক পাবেন।)*

## কম্পিউটার/লোকাল টেস্টিং

**সহজ উপায় (ভয়েস ছাড়া সবকিছু কাজ করবে, ইনস্টল অপশন আসবে না):**
`index.html` ফাইলে সরাসরি ডাবল-ক্লিক করে যেকোনো ব্রাউজারে খুলুন — সার্চ, ফাজি ম্যাচিং, ফিল্টার, সাজেশন সব কাজ করবে।

**ভয়েস সার্চসহ টেস্ট করতে (Live Server):**
1. VS Code-এ পুরো `foshol-bondhu` ফোল্ডার খুলুন
2. `index.html`-এ রাইট-ক্লিক → **Open with Live Server**
3. মাইক আইকনে ট্যাপ করে পারমিশন দিন — ভয়েস সার্চ চালু হয়ে যাবে (Chrome-এ সবচেয়ে ভালো কাজ করে)

## 🗂️ গুগল শীট এখন লাইভ ডেটাবেস

`data-loader.js` ফাইলে আপনার শীটের CSV এক্সপোর্ট লিংক বসানো আছে। অ্যাপ চালু হলেই সরাসরি শীট থেকে সব সারি নিয়ে আসে — **শীটে নতুন ওষুধ যোগ করলে অ্যাপ রিলোড দিলেই সেটা দেখা যাবে, কোনো কোড পরিবর্তন লাগবে না।**

**শর্ত:** শীটের Share সেটিংস "Anyone with the link → Viewer" হতে হবে (এখন যেভাবে আছে, সেভাবেই কাজ করবে)।

**কলাম অর্ডার যেভাবে ধরে নেওয়া হয়েছে** (`data-loader.js`-এর `rowsToRecords` ফাংশনে):
```
ক্রমিক নং | কোম্পানীর নাম | ব্র্যান্ড/ওষুধের নাম | সক্রিয় উপাদান | বালাইনাশকের ধরণ (যেমন: "কীটনাশক (Insecticide)") | প্রস্তুত প্রণালী | প্রয়োগ ক্ষেত্র ও কাজ
```
শীটে কলামের অর্ডার এর চেয়ে ভিন্ন হলে, বা একাধিক ট্যাব থাকলে (ভিন্ন `gid`), `data-loader.js`-এর শুরুতে `SHEET_GID` ভ্যারিয়েবল ও `rowsToRecords` ফাংশনের `row[0], row[1]...` ইনডেক্সগুলো মিলিয়ে নিতে হবে।

**যদি লাইভ শীট লোড ব্যর্থ হয়** (ইন্টারনেট না থাকলে, বা শেয়ারিং পাবলিক না থাকলে) — অ্যাপ স্বয়ংক্রিয়ভাবে `fallback-data.js`-এর ৯৯টা বান্ডিল করা নমুনা ডেটায় ফিরে যাবে, অ্যাপ ভাঙবে না। হেডারে কোন ডেটা ব্যবহার হচ্ছে তা "🟢 লাইভ শীট থেকে" বা "🟡 অফলাইন ডেটা" ব্যাজ দিয়ে দেখানো হয়।

## এই ডেমোতে যা আছে

- 🔍 **টেক্সট সার্চ** — রোগের নাম, ওষুধের ব্র্যান্ড নাম, বা সক্রিয় উপাদান দিয়ে
- 🎙️ **ভয়েস সার্চ** — Web Speech API (বাংলা ভাষা `bn-BD`)
- 🌐 **ক্রস-ল্যাঙ্গুয়েজ ম্যাচিং** — "ফিপ্রোনিল" লিখলে "Fipronil" পাবেন, আবার "agacha" লিখলে "আগাছানাশক" পাবেন
- ✍️ **বানান-ভুল সহনশীল** — Levenshtein ফাজি ম্যাচিং দিয়ে "fiproneel" লিখলেও "Fipronil" পাওয়া যাবে
- 🤔 **"আপনি কি এটি খুঁজছেন?"** — যখন সার্চ টার্ম অস্পষ্ট, তখন সম্ভাব্য মিল সাজেস্ট করে; কখনো একদম খালি ফলাফল দেখায় না
- 🏷️ ক্যাটাগরি ফিল্টার (কীটনাশক/ছত্রাকনাশক/আগাছানাশক/মাকড়নাশক)
- 🗂️ **লাইভ গুগল শীট ইন্টিগ্রেশন** — কোনো ব্যাকএন্ড ছাড়াই সরাসরি শীট থেকে ডেটা
- 📲 **PWA — Android/iOS-এ ইনস্টলযোগ্য**, হোম স্ক্রিন আইকন, ফুল-স্ক্রিন মোড, অফলাইন সাপোর্ট (সার্ভিস ওয়ার্কার)
- 📱 সম্পূর্ণ মোবাইল-ফার্স্ট, প্রকৃত অ্যাপের মতো UI (বটম ন্যাভিগেশন সহ)

## ফোল্ডার স্ট্রাকচার

```
foshol-bondhu/

├── index.html          ← মূল পেজ (PWA মেটাডেটাসহ)
├── manifest.json         ← PWA ইনস্টলযোগ্যতার জন্য (আইকন, নাম, থিম কালার)
├── sw.js                  ← সার্ভিস ওয়ার্কার (অফলাইন ক্যাশিং)
├── style.css              ← ডিজাইন সিস্টেম (ধানক্ষেত-অনুপ্রাণিত রঙ ও টাইপোগ্রাফি)
├── data-loader.js         ← গুগল শীট থেকে লাইভ CSV ফেচ + পার্স করার লজিক
├── fallback-data.js       ← অফলাইন ব্যাকআপ (৯৯টি নমুনা, শীট লোড ব্যর্থ হলে ব্যবহৃত হয়)
├── search-engine.js       ← ফাজি ম্যাচিং + ফোনেটিক ট্রান্সলিটারেশন লজিক
├── app.js                 ← UI রেন্ডারিং, ভয়েস রিকগনিশন, PWA ইনস্টল প্রম্পট
└── icons/                 ← অ্যাপ আইকন (192px, 512px, maskable, iOS)
```

## বর্তমান সীমাবদ্ধতা (এটা প্রোটোটাইপ, প্রোডাকশন AI না)

| এখন যা আছে | কেন এটা সীমিত |
|---|---|
| রুল-বেইজড ফাজি ম্যাচিং (Levenshtein + character-level phonetic map) | আসল ভাষাগত বোঝাপড়া নেই — জটিল বাক্য বা প্রসঙ্গ বুঝবে না |
| মাত্র ৯৯টি নমুনা পণ্য (আপনার শীটের একটা অংশ থেকে জেনারেট করা প্যাটার্ন) | আসল ২ লক্ষ+ এন্ট্রি ডেটাবেসে যুক্ত করা হয়নি |
| ব্রাউজারের নিজস্ব স্পিচ রিকগনিশন (Web Speech API) | ইন্টারনেট কানেকশন লাগে, গ্রামীণ/আঞ্চলিক উচ্চারণে নির্ভুলতা কম হতে পারে |
| কোনো ব্যাকএন্ড/ডেটাবেস নেই | ডেটা আপডেট করতে কোড এডিট করতে হয়, ইউজার হিস্ট্রি সেভ হয় না |
| রোগ নির্ণয় নেই, শুধু নাম-ম্যাচিং | ছবি দেখে রোগ শনাক্ত করতে পারে না |

## রোডম্যাপ — "সম্পূর্ণ কৃষি বিশেষজ্ঞ AI" বানাতে যা যোগ করতে হবে

এই ডেমো একটা ভিত্তি মাত্র। ভবিষ্যতে সম্পূর্ণ AI বানাতে ধাপে ধাপে যা যোগ করা যায়:

1. **ডেটাবেস সম্প্রসারণ** — পুরো ২ লক্ষ+ এন্ট্রি একটা আসল ডেটাবেসে (MongoDB/PostgreSQL) নিয়ে যাওয়া, ব্যাকএন্ড API দিয়ে সার্ভ করা (যেমন আগে বানানো Dokan ব্যাকএন্ডের ধাঁচে)
2. **আসল NLP/embedding-ভিত্তিক সার্চ** — বর্তমান rule-based ফাজি ম্যাচিং-এর বদলে semantic embedding (যেমন multilingual sentence-transformer) ব্যবহার করলে অর্থ বুঝে সার্চ করতে পারবে, শুধু বানান মেলানো না
3. **ছবি দিয়ে রোগ শনাক্তকরণ** — ফসলের পাতার ছবি তুলে আপলোড করলে AI মডেল (computer vision) দিয়ে রোগ শনাক্ত করে সরাসরি প্রাসঙ্গিক ওষুধ দেখানো (বটম ন্যাভে "ছবি স্ক্যান" আইকনটা এই ফিচারের জন্য জায়গা রাখা আছে)
4. **সার্ভার-সাইড স্পিচ-টু-টেক্সট** — আঞ্চলিক ভাষা/উচ্চারণে আরও নির্ভুল ফলাফলের জন্য একটা ডেডিকেটেড বাংলা STT মডেল (Google Cloud Speech বা নিজস্ব ফাইন-টিউনড মডেল)
5. **কথোপকথনমূলক AI সহায়ক** — একটা LLM (যেমন Claude API) যুক্ত করলে কৃষক শুধু ওষুধের নাম না, উপসর্গ বর্ণনা করেও ("আমার ধান গাছের পাতা হলুদ হয়ে যাচ্ছে") পরামর্শ পেতে পারবেন
6. **ডোজ ও প্রয়োগ ক্যালকুলেটর** — জমির আয়তন দিলে সঠিক ডোজ হিসেব করে দেওয়া
7. **আবহাওয়া ইন্টিগ্রেশন** — কখন স্প্রে করা নিরাপদ (বৃষ্টি/বাতাসের পূর্বাভাস অনুযায়ী)
8. **ইউজার প্রোফাইল ও হিস্ট্রি** — কৃষকের জমির তথ্য, আগের সার্চ, প্রিয় ওষুধ সেভ রাখা
9. **বিশেষজ্ঞ যোগাযোগ** — সরাসরি কৃষি সম্প্রসারণ কর্মকর্তার সাথে চ্যাট/কল ("বিশেষজ্ঞ" ট্যাব এই জন্য প্রস্তুত)
10. **অফলাইন সাপোর্ট** — নেটওয়ার্ক দুর্বল এলাকার জন্য PWA + ক্যাশড ডেটাবেস

কোনটা আগে যোগ করতে চান বললে, সেটা দিয়েই এগিয়ে যাই — যেমন এখনই যদি চান, পুরো শীটের বাকি ডেটা (১ লক্ষ ৯৯ হাজার ৯০০+ এন্ট্রি) প্রসেস করে ডেটাবেসে নিয়ে যাওয়া শুরু করতে পারি, অথবা Claude API যুক্ত করে "উপসর্গ বলুন, রোগ চিনিয়ে দেব" ফিচারটা বানাতে পারি।
